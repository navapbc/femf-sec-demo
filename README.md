# sec-demo

Temporary hosting for a **design prototype** of a modernized SEC.gov, shared for
stakeholder review.

**This is not an official SEC website.** It is an unaffiliated, non-functional
design mockup. It is not published, endorsed, or approved by the U.S. Securities
and Exchange Commission. Content shown in the prototype is illustrative only —
do not rely on it for any purpose. For official information, see
[sec.gov](https://www.sec.gov).

This repository is expected to be taken offline shortly after review.

## Contents

| File | What it is |
| --- | --- |
| `index.html` | Launch page — start here |
| `00-sec-homepage-preview_20260812.html` | Homepage prototype |
| `01-sec-landing-preview_20260812.html` | Landing page prototype |
| `02-sec-content-preview_20260812.html` | Content page prototype |
| `secds-standalone_20260812.html` | Design system reference |

Each file is self-contained — fonts, images, and styles are inlined, so pages
work with no network access beyond the initial load.
